# Unes de journaux des joueurs

Une image par joueur (la « une » faite par Tom en début de saison), utilisée dans le format court du mercredi « Joueur de la semaine ».

Nom du fichier : le prénom en minuscules, sans accent, comme dans assets/portraits :
kilian.jpg, francois.jpg, samuel.jpg, johnny.jpg, nico.jpg, kevin.jpg, vincent.jpg, jo.jpg, keanu.jpg, jehan.jpg,
joachim.jpg, tom.jpg, thomas.jpg, fredo.jpg, ayrton.jpg, selba.jpg, tony.jpg, erwann.jpg, nicolas_f.jpg
(.jpg ou .png).

Le texte de la une (titres, infos, second degré) est validé par Tom : il peut servir de gag dans le court,
dans le respect des lignes rouges de la bible. Le détail des unes (titres réutilisables, unes à valider) est dans la bible.

Les images sont recadrées en 1080x1920 (une entière centrée sur fond flouté) : utiliser `"opts": {"n": 1}` et une seule
ligne de texte courte sur ce plan. Modèle : shorts/2026-11-25_joueur.json.
