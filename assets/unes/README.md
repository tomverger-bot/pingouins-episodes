# Unes de journaux des joueurs

Tom a fait en début de saison une une de journal par joueur, en second degré. Règle de Tom (25/11/2026) :
les unes n'apparaissent JAMAIS dans les vidéos, elles servent seulement d'inspiration pour les textes du format
« Joueur de la semaine ». Leurs titres et gags réutilisables sont recopiés dans la bible (projet claude.ai),
section « Unes de journaux des joueurs » : c'est là qu'il faut les lire. Aucune image n'est nécessaire dans ce dossier.
